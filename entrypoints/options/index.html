Network capture rules

Rules are evaluated top-down; the first match wins. Each rule may match on domain (host glob), path (path glob or /regex/flags) and status (5xx, 4xx, 429, 400-499, or an exact code). default is applied when nothing matches.

Example configuration 
{
  "rules": [
    { "domain": "*.analytics.com", "action": "ignore" },
    { "path": "/health", "action": "ignore" },
    { "status": "5xx", "action": "capture" },
    { "status": "4xx", "action": "capture" }
  ],
  "default": "ignore"
}
